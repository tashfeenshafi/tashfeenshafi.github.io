Research — KSU Robotics Lab

Tripedal locomotion: a design decision log

Most walking robots are over-engineered. They use too many motors, which drives up weight and cost. Our group wanted to strip that complexity out — a tripedal robot using crutch-assisted walking geometry, math instead of motors, as a cheaper base for robotics research.

Three concepts went on the table. Two didn't survive review. What follows is why.

Not selected

Concept A — my pitch

Minimum part count to keep it light. It solved the weight problem, but simulation showed it was unstable: a nudge from front or back would tip it. We killed it.

Not selected

Concept B — teammate

Better range of motion, and a genuinely good concept. The knee joint needed manufacturing precision our budget and timeline couldn't buy.

Built

Hybrid — final

Fixed the stability failure in Concept A without buying Concept B's machining complexity. This is what went to fabrication.

Build phase

With the CAD locked, we fabricated in standard COTS aluminum framing. Not fancy — but it let us test the geometry in days instead of waiting weeks on custom parts, which was the entire point of the project.

The next phase is control software: stair climbing and obstacle handling, proving you don't need expensive hardware to move well.

Automation

Cutting the hand-work out of an HDR pipeline

Running a photography business handed me a clean bottleneck: aligning and merging HDR brackets took about five minutes per set by hand. On a 500-photo shoot, that's a full day of work a machine should be doing.

The script hooks into the Hugin toolstack to sort, align, and fuse automatically — roughly 40% off my active working time per shoot, and it runs unattended. 

# Core logic for batch processing HDR groups
def process_groups(groups, output_folder, align_tool, enfuse_tool):
    if not os.path.exists(output_folder): os.makedirs(output_folder)

    for group in groups:
        # 1. Setup paths
        base_name = os.path.splitext(os.path.basename(group[0]))[0]
        output_file = os.path.join(output_folder, f"{base_name}_fused.tif")
        aligned_prefix = os.path.join(output_folder, "temp_aligned_")

        # 2. Align images using Hugin toolstack
        subprocess.run([align_tool, "-m", "-a", aligned_prefix] + group)
        aligned_files = glob.glob(aligned_prefix + "*.tif")

        # 3. Fuse aligned images into final HDR output
        cmd = [
            enfuse_tool, "--output", output_file,
            "--exposure-weight=1.0", "--saturation-weight=0.2", "--contrast-weight=0"
        ] + aligned_files
        subprocess.run(cmd)

        # 4. Cleanup temp files
        for f in aligned_files: os.remove(f)

Abbreviated to show the logic — the working script handles errors, mismatched group sizes, and file management.
